# MidtermProject
Midterm exocomet project
Project purpose:
Understand the distribution of exocomets in our universe. Exocomets are crucial to understanding planet formation and newly discovered interstellar objects. With this streamlight application you will be able to easily compare and contrast exocomet populations and comet populations. 

Data sources:
Data has come from the astrophysical data system, from several different published journals. Lecavelier des Etangs, A., Cros, L.,H´ebrard, G., et al. 2022, Scientific Reports, 12, 5855, doi: 10.1038/s41598-022-09021-2. The data file creation is done in notebooks/data_readout.ipynb. 

Setup instructions:
Download the contents of this repository and run the analysis.ipynb notebook to access the streamlight application. Exploring notebooks/analysis.ipynb will allow for a more in depth understanding of the data analysis that went into the user-friendly streamlight application. 
An environment with the specifications denoted in requirements.txt is required to run the notebooks and streamlight application locally.
`conda/pip install -r requirements.txt` inside your environment. 

Key limitations:
Only two exocomet systems are included here, which significantly limits the ability for us to compare to solar system populations to the exocomet populations. 
The exact individual radii of these exocomet populations is not included here, simply a best fit to the exocomet population.
